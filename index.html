3. Caso de Estudio Destacado: SpringEduManager

Descripción: Desarrollo de una aplicación web interna para digitalizar y centralizar el registro de estudiantes de un bootcamp tecnológico.

Desafío principal: Migrar la gestión tradicional basada en hojas de cálculo hacia un sistema web seguro que diferenciara los permisos de escritura y lectura entre administradores y usuarios comunes.

Solución propuesta: Implementación de una arquitectura MVC con un sistema de autenticación por roles (ADMIN y USER) y una base de datos en memoria para el acceso persistente a la información.

Herramientas: Java 17, Spring Boot, Spring Security, Spring Data JPA, H2 Database, Maven y Thymeleaf.

Principales aprendizajes: Configuración del ciclo de vida de un proyecto backend, securización de vistas HTML contra ataques CSRF y disponibilización de información a través de endpoints RESTful.

Métricas de impacto: Despliegue de un entorno funcional rápido y sin dependencias externas mediante H2, logrando protección total de las rutas de guardado de datos.

Habilidades técnicas aplicadas: Desarrollo backend, modelado de bases de datos relacionales, gestión de dependencias y seguridad web.
